# rviz/ — layouts de visualização do RViz2

Configurações salvas do RViz2 para enxergar a navegação durante os testes
(mapa, nuvem de partículas do AMCL, costmap, plano global do Nav2, pose).

| Arquivo (a criar)   | Semana | O que mostra |
|---------------------|--------|--------------|
| `navegacao.rviz`    | 3      | Mapa + pose estimada (AMCL) + rota do Nav2 + leituras do LiDAR. |

> Gera-se assim: abrir o RViz2, montar os displays, `File > Save Config As`
> aqui dentro. É evidência visual boa para a arguição oral.
